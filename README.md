# J66 - Visual Filters Studio

A luxurious, cinematic visual filters platform specializing in glow effects, blur treatments, grain textures, and premium digital aesthetics for creative professionals.

## 🎨 Features

- **Cinematic Filter Library**: 120+ custom presets for digital storytelling
- **Visual Effects System**: Glow, Blur, Grain, Duotone, and Split Tone treatments
- **Premium Aesthetics**: Velvet Noir, Solar Fade, Prism Mist, and more
- **Creative Workflow**: Frame → Layer → Refine visual design process
- **Responsive Design**: Optimized for desktop, tablet, and mobile
- **Dark Luxury Theme**: Modern UI with cinematic gradients and animations

## 🚀 Quick Start

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/tt900/j66-visual-effects.git
cd j66-visual-effects
```

2. Open in browser:
```bash
# Simply open index.html in your browser
open index.html
```

Or use a local server:
```bash
# Python 3
python -m http.server 8000

# Node.js (with http-server)
npx http-server
```

3. Navigate to `http://localhost:8000`
